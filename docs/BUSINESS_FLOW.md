# Notecast 课程材料转笔记业务流程

> 最后更新：2026-09-01  
> 状态：当前  
> 适用范围：`lib/features/workflow` 与 `lib/services`

## 入口与前置条件

- 入口：App 内录音、系统文件选择器、macOS/Windows 桌面拖拽。
- 权限：录音需要麦克风；在线 AI 会把用户选择的材料传给配置的 Provider；Vault 需要用户选择目录。
- 前置配置：音频路径需要转写服务；所有笔记生成需要笔记服务地址与模型；本地服务必须由用户自行启动。
- 非目标：账号、云同步、实时字幕、说话人分离、自动转码、长音频切片和模型内置。

## 主流程

1. 用户录音或导入音频/UTF-8 文本。
2. 客户端先保存或验证本地源文件；文本直接成为课程材料，音频上传转写端点。
3. 笔记 Provider 根据课程材料返回结构化 JSON。
4. MarkdownService 确定性生成含来源、概要、章节、概念、例子、复习题、待核实内容和完整材料的 Markdown。
5. 用户编辑/预览后导出 `.md`；桌面端可写入所选 Vault 的 `01-课程笔记/`。

## 状态、异常与边界

| 场景 | 系统行为 | 用户反馈 | 可恢复方式 |
|---|---|---|---|
| 麦克风未授权 | 不开始录音 | 指向系统权限设置 | 授权后重试 |
| 非法/空/非 UTF-8 文件 | 拒绝进入流程 | 说明支持格式或编码 | 转换或重新选择 |
| 文本导入 | 跳过转写 | 按钮显示“根据文本生成笔记” | 重新导入不覆盖源文件 |
| API 地址、Key 或网络错误 | 停止当前 AI 阶段 | 区分权限、额度、服务端和连接错误 | 修改设置后重试；本地源文件保留 |
| Provider 不支持音频格式/大小 | 转写失败 | 显示服务响应或友好错误 | 转码、切分或更换 Provider |
| Vault 同名文件 | 不覆盖原笔记 | 生成带时间戳的新文件 | 用户自行整理 |
| Android Vault | 不直接承诺任意 Vault 写入 | 仅提供系统导出 | 由用户导入 Obsidian |

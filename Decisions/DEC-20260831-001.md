# DEC-20260831-001：Flutter 单代码库与 OpenAI-compatible Provider

## 状态与关联

- 状态：已完成
- 关联需求：`REQ-20260831-001`

## 问题与约束

个人开发者需要同时覆盖 macOS、Windows、Android，并接入可替换转写/笔记服务；原始资料应本地优先，不能将业务锁进某一家云服务。

## 方案比较

| 方案 | 收益 | 代价/风险 |
|---|---|---|
| Flutter 单代码库 | UI 与业务逻辑复用，适合个人维护 | 原生插件和平台发布仍需分别验证 |
| Electron + Android 独立 | 桌面生态成熟 | 两套移动/桌面实现，资源占用更高 |
| 全原生 | 平台能力最佳 | 三套代码，超出当前个人开发成本 |

## 已确认方案

- Flutter 管理 UI 与工作流；录音、文件、安全存储通过窄插件接口接入。
- 转写和笔记服务使用 OpenAI-compatible HTTP 端点；Ollama 仅负责笔记模型，不被假定为转写服务。
- AI 返回结构化 JSON，客户端确定性渲染 Markdown；API Key 进入系统安全存储。
- 无数据库迁移；本地偏好可以通过重新配置恢复。

## 实施与验证

模块见 `docs/PDD.md`。验证证据为 9 项测试、macOS/Windows GitHub Actions 构建和 `v1.1.1` Release。Android 用户路径仍待实机回归。

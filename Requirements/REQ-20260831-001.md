## 背景与目标

面向长期记录中文课程的用户，将录音、已有音频或文本整理为可编辑、可移植的 Obsidian Markdown，资料优先保存在本地，AI Provider 可替换。

## 已确认需求

- 主流程：录音或导入 → 必要时转写 → AI 结构化整理 → 编辑/预览 → `.md` 或 Vault。
- 包含：macOS/Windows 桌面 V1；Android 同代码库基础工程；音频与 UTF-8 文本输入；本地/在线兼容 API；安全存储 API Key。
- 不包含：账号、云同步、实时字幕、说话人分离、自动转码、断点续传、模型内置和服务端额度代理。
- 安全边界：录音与 Markdown 属于用户；密钥不进入源码、普通偏好或 Git；在线 API 会接收所选课程材料。
- 验收：桌面安装包可构建；输入、笔记、导出入口可用；Markdown 结构稳定；发布文件可下载并校验。
